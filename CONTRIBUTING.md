# Contributor covenant — cinnamon-sysmon-text

**This repository is maintained exclusively by [@NurMohammadDuari](https://github.com/NurMohammadDuari/).**

- Only the repository owner may merge/push to `main` (enforced via branch protection + [`CODEOWNERS`](.github/CODEOWNERS)).
- External contributions are **not accepted** via pull requests at this time.
- You can still contribute by:
  - 🐛 opening a detailed **bug report** (Cinnamon version, Mint version, steps to reproduce)
  - 💡 opening a **feature request**

Thank you for understanding!
